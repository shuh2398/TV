## Быстрый старт для заместителя

1. Откройте нужный файл (например, `execution.md`).
2. Нажмите на иконку карандаша (✏️ Edit).
3. Внесите изменения в таблицу.
4. Внизу страницы напишите краткое описание изменений и нажмите
   **«Propose changes»**.
5. На следующем экране нажмите **«Create pull request»**.
6. Дождитесь одобрения от аппарата заместителя хакима области.
