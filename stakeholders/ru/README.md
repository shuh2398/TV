# Стейкхолдеры — Россия (Кировская область)

Каталог потенциальных участников сотрудничества со стороны РФ.

## Правила ведения

1. На каждого стейкхолдера — отдельный файл `<slug>.md`.
2. До включения любой российской организации в рабочие документы —
   провести санкционный скрининг (см. `../../risks/sanctions-check.md`)
   и зафиксировать его результат в карточке.
3. Не приписывать «интерес», «поддержку», «готовность» без письма,
   протокола, публичного заявления — см. `.cursorrules`.
4. Должности — с датой и ссылкой на источник.

## Категории (ориентир — подтвердить по актуальной структуре)

- Правительство Кировской области.
- Министерство экономического развития / профильные министерства.
- Региональная корпорация/агентство развития (если существует и
  функционирует — уточнить, `НЕ ЗНАЮ ДОСТОВЕРНО`).
- Законодательное собрание Кировской области (профильные комитеты).
- ТПП Кировской области.
- Отраслевые союзы и кластерные объединения.
- Крупные предприятия региона (по подтверждённому перечню).
- Академические и отраслевые НИИ.
