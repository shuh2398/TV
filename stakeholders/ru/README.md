# Стейкхолдеры — российская сторона

В этом каталоге хранятся карточки органов власти, институтов
развития, ассоциаций и компаний Российской Федерации
(в первую очередь — Кировской области), рассматриваемых в
качестве потенциальных партнёров.

## Обязательная процедура перед созданием карточки

1. Выполнить санкционную проверку по
   [`risks/sanctions-check.md`](../../risks/sanctions-check.md).
2. Зафиксировать дату проверки и её результат в карточке.
3. Проверить наличие публичных данных о бенефициарах и
   структуре собственности.

Без этих шагов карточка не создаётся.

## Структура карточки

Каждая организация — отдельный файл `<slug>.md`. Рекомендуемый
состав:

- полное фирменное наименование (в оригинале на русском);
- организационно-правовая форма;
- ИНН / ОГРН / КПП (из ЕГРЮЛ);
- юридический и фактический адреса;
- ОКВЭД (основной и дополнительные);
- бенефициары и структура собственности (по данным
  официальных источников);
- руководитель (ФИО, должность) — со ссылкой;
- контакты: телефон, e-mail, сайт (с датой проверки);
- **санкционная проверка**: дата, перечень списков, результат,
  ссылка на скриншот/архив;
- роль в проекте;
- подписанные документы с участием организации (с реквизитами);
- открытые вопросы (ссылки на `questions-open.md`).

## Правила

1. Никаких утверждений о заинтересованности компании в
   сотрудничестве без подписанного меморандума/письма или
   публичного заявления первого лица.
2. Если компания или её бенефициар находятся под санкциями
   (любого из применимых списков) — в карточке обязательно
   поле `blocked: true` с указанием списка и даты включения;
   дальнейшая работа с такой организацией возможна только
   после юридической экспертизы.
3. Реквизиты берутся из ЕГРЮЛ, а не из корпоративных
   презентаций.
