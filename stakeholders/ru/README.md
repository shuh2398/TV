# Stakeholders — Россия (Кировская область)

Карточки заинтересованных сторон со стороны Российской Федерации:
органы власти региона, институты развития, компании, ассоциации,
торгово-промышленные палаты.

## Структура файла

Один стейкхолдер = один файл `<краткое-имя>.md` в этой папке.

- **EU consolidated list:** проверено `YYYY-MM-DD`
- **UK HMT consolidated list:** проверено `YYYY-MM-DD`
- **Вторичные санкции (риск для контрагентов РУз):** оценка
- **Итог:** допустим как партнёр / не допустим / требует согласования

## Правила

1. Без пройденной санкционной проверки компания помечается как
   «кандидат, не проверен» и не включается в рекомендации.
2. Нельзя указывать заинтересованность/намерения компании без
   задокументированного подтверждения.
3. ФИО — только из открытых официальных источников.
