# Стейкхолдеры — узбекистанская сторона

В этом каталоге хранятся карточки органов власти, институтов
развития, ассоциаций и компаний Республики Узбекистан,
участвующих в работе по инвестиционному потенциалу
Кашкадарьинской области.

## Структура карточки

Каждая организация — отдельный файл `<slug>.md`. Рекомендуемый
состав:

- полное название (на узбекском — в оригинале, на русском —
  рабочий перевод);
- организационно-правовая форма;
- руководитель (ФИО, должность) — только со ссылкой на
  официальный источник назначения;
- юридический адрес;
- ИНН / ОКПО / иные реквизиты (если публично доступны);
- контакты: телефон, e-mail, сайт (с датой проверки);
- роль в проекте (регулятор, партнёр, подрядчик, оператор СЭЗ,
  отраслевая ассоциация и т. д.);
- подписанные документы с участием организации (с реквизитами);
- открытые вопросы (ссылки на `questions-open.md`).

## Правила

1. ФИО и должности — только со ссылкой на указ, постановление,
   приказ о назначении, официальный сайт или официальное
   сообщение пресс-службы.
2. Реквизиты — только из публичных реестров (например,
   соответствующих государственных реестров РУз).
3. Утверждения вида «поддерживает проект» / «готовы участвовать»
   — только при наличии подписанного документа. Иначе —
   «НЕ ЗНАЮ ДОСТОВЕРНО» и пункт в `questions-open.md`.
