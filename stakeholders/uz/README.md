# Stakeholders — Узбекистан (Кашкадарьинская область)

Карточки заинтересованных сторон со стороны Республики Узбекистан:
органы власти, институты развития, компании, ассоциации.

## Структура файла

Один стейкхолдер = один файл `<краткое-имя>.md` в этой папке.

Шаблон:

```markdown
# <Официальное название (оригинал, uz/ru)>

- **Тип:** госорган / институт развития / компания / ассоциация / иное
- **Локация:**
- **Официальный сайт:**
- **Контактное лицо (должность):** _только при наличии открытого источника_
- **ФИО контактного лица:** _только при наличии открытого источника;
  иначе — НЕ ЗНАЮ ДОСТОВЕРНО_
- **Телефон / e-mail:**
- **Источник данных:** `S-YYYY-NNN`

## Роль в проекте

`[ФАКТ]` / `[ГИПОТЕЗА]` / `[ОЦЕНКА]` — …

## История взаимодействия

| Дата | Формат | Тема | Результат | Документ/источник |
| ---- | ------ | ---- | --------- | ----------------- |

## Открытые вопросы

- [ ] …  (продублировать в ../../questions-open.md)
```

## Правила

1. Нельзя указывать заинтересованность/намерения организации без
   задокументированного подтверждения (письмо, пресс-релиз, протокол).
2. ФИО — только из открытых официальных источников.
3. Официальные названия — в оригинале.
