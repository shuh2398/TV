# Стейкхолдеры — Узбекистан

Каталог участников инвестиционного процесса со стороны РУз
(Кашкадарьинская область и центральные органы).

## Правила ведения

1. На каждого стейкхолдера — отдельный файл `<slug>.md`.
2. Персональные контакты — только публичные (с официального сайта или
   официально переданные). Личные мобильные/мессенджеры — не
   публиковать в репозитории.
3. Должности указывать **по состоянию на дату**, со ссылкой на
   источник (официальный приказ/публикация).
4. Не приписывать позициям и людям намерений, поддержки или интереса
   без документа — см. `.cursorrules`.

## Категории

- Хокимият Кашкадарьинской области.
- Заместители хокима по направлениям.
- Агентство по продвижению инвестиций РУз (UzIPA).
- Министерство инвестиций, промышленности и торговли РУз.
- ТПП Республики Узбекистан / областное отделение.
- Отраслевые ассоциации (при наличии).
- Администрация СЭЗ (при наличии конкретной зоны в области).
- Банки, профильные по ВЭД.

## Шаблон карточки

```markdown
# <ФИО / Название организации>

- **Роль/должность:** (на YYYY-MM-DD)
- **Организация:**
- **Публичные контакты:**
  - Сайт:
  - Приёмная / телефон:
  - E-mail:
- **Полномочия / сфера ответственности:** (кратко, со ссылкой)
- **История взаимодействия:** (протоколы, письма — со ссылками на файлы в репо)
- **Источники:**
```
