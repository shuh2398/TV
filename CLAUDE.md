# CLAUDE.md — Правила работы с репозиторием

## Рабочий язык

**Русский.** Все ответы, комментарии и документы — на русском языке,
если явно не указано иное.

---

## Обязательные правила (нарушение недопустимо)

### 1. Запрет на цифры без источника

Любое числовое утверждение — площадь, объём инвестиций, численность
населения, ВРП, объём производства, количество предприятий и т.д. —
**обязательно** сопровождается ссылкой на источник в формате:

```
значение [источник: <ID из data/sources.md> или <URL>]
```

Если источник неизвестен — **не писать цифру**. Написать:
> НЕ ЗНАЮ ДОСТОВЕРНО: [описание недостающих данных]

и добавить вопрос в `questions-open.md`.

### 2. Запрет на утверждения о заинтересованности компаний

Нельзя писать, что компания «заинтересована», «рассматривает»,
«планирует», «ведёт переговоры» и т.п. **без документального факта**:
подписанного протокола, письма, меморандума или публичного заявления.

Вместо этого писать:
> НЕ ЗНАЮ ДОСТОВЕРНО: наличие интереса со стороны [название компании]
> не подтверждено документально.

### 3. Правило «НЕ ЗНАЮ ДОСТОВЕРНО»

При отсутствии проверенных данных по любому значимому вопросу:
1. Написать `НЕ ЗНАЮ ДОСТОВЕРНО: <описание>`.
2. Добавить вопрос в `questions-open.md` с датой и контекстом.
3. Не заполнять поле заглушками или предположениями.

### 4. Ссылки на источники

Каждое значимое утверждение в документах должно содержать ссылку:
- на файл в репозитории: `[источник: data/verified/kashkadarya.yaml]`
- на внешний URL: `[источник: https://...]`
- на реестровую запись: `[источник: SRC-001]` (см. `data/sources.md`)

### 5. Работа с YAML-данными

- Поля с неизвестными значениями заполняются как `null`.
- Поле `source` обязательно для каждого значения — даже для `null`.
- Не удалять поля-заглушки, не заменять `null` на предположения.

---

## Структура репозитория

| Путь | Назначение |
|------|-----------|
| `data/verified/` | Проверенные данные с источниками |
| `data/raw/` | Сырые данные до верификации |
| `data/sources.md` | Реестр всех источников |
| `projects/` | Карточки инвестиционных проектов |
| `projects/_template.md` | Шаблон карточки проекта |
| `stakeholders/uz/` | Стейкхолдеры — узбекская сторона |
| `stakeholders/ru/` | Стейкхолдеры — российская сторона |
| `risks/` | Анализ рисков |
| `questions-open.md` | Открытые вопросы без ответа |

---

## Процесс добавления данных

1. Найти первичный источник (постановление, статистика, официальный сайт).
2. Зарегистрировать источник в `data/sources.md` (присвоить ID).
3. Внести данные в `data/verified/*.yaml` со ссылкой на ID источника.
4. Если данных нет — зафиксировать в `questions-open.md`.

---

## Запрещено

- Генерировать «примерные» или «ориентировочные» цифры без источника.
- Копировать данные из непроверенных источников без пометки `[непроверено]`.
- Удалять записи из `questions-open.md` без реального ответа.
- Писать на языке, отличном от русского, без явного запроса пользователя.
