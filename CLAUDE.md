# CLAUDE.md

Этот файл читается Claude Code при работе в репозитории.
Главные правила вынесены в [`.cursorrules`](.cursorrules) — там же
действуют для Cursor и любых других ассистентов. Здесь — короткая
выжимка.

## Рабочий язык

**Русский.** Официальные названия документов, организаций и НПА — в
оригинале (узбекский / русский / английский), при необходимости с
переводом в скобках.

## Тема репозитория

Инвестиционный потенциал **Кашкадарьинской области Республики
Узбекистан** и поиск партнёров в **Кировской области Российской
Федерации**.

## Главные правила (короткой строкой)

1. **Никаких цифр без `source`.** В YAML — поле `source` обязательно.
   В Markdown — ссылка на источник в строке утверждения.
2. **Никаких утверждений о заинтересованности компаний или людей**
   без задокументированного факта (письмо, протокол, публичное
   заявление). Слова «заинтересован», «планирует», «ведёт переговоры»
   — только с документом.
3. Если данных нет — пишем буквально: **`НЕ ЗНАЮ ДОСТОВЕРНО`** и
   добавляем пункт в [`questions-open.md`](questions-open.md).
4. Маркировать природу утверждения: `[ФАКТ]` / `[ГИПОТЕЗА]` / `[ИДЕЯ]`
   / `[НЕ ЗНАЮ ДОСТОВЕРНО]`.
5. Российские контрпартии — **только** через санкционный скрининг по
   [`risks/sanctions-check.md`](risks/sanctions-check.md). До
   завершения скрининга — не включать в рабочие документы.

## Куда что класть

| Что | Куда |
| --- | --- |
| Проверенные числовые/фактологические данные | `data/verified/*.yaml` |
| Сырые материалы (выписки, скриншоты, PDF) | `data/raw/<тип>/` |
| Реестр источников | `data/sources.md` |
| Карточки проектов | `projects/<slug>.md` (по `projects/_template.md`) |
| Стейкхолдеры | `stakeholders/uz/`, `stakeholders/ru/` |
| Санкционный скрининг | `risks/sanctions-check.md` (+ `risks/screenings/` при необходимости) |
| Открытые вопросы | `questions-open.md` |

## Что запрещено

- Выдумывать цифры, названия, контакты.
- Заполнять шаблоны «правдоподобными» значениями.
- Ссылаться на «обычно», «по аналогии», «типичные для региона» как
  на факт.
- Писать про российские компании в ключе сотрудничества без
  санкционного скрининга.
- Использовать анонимные Telegram-каналы и форумы как источник.

Полный список правил, формат блока `source`, приоритет источников и
порядок действий при пропусках — в [`.cursorrules`](.cursorrules).
