## 5. Что это значит для Кашкадарьинской области

`[ГИПОТЕЗА на основе ФАКТОВ выше]`

### 5.1. Проект SHANAZ — валидация тезиса

То, что частный инициатор готов вложить **$12,5 млн** в смешанное
производство фарма+косметика+бытовая химия+БАДы+органика именно
в **2025 году** на фоне рекордных импортов, **подтверждает** наш
вывод из `household-chemicals-market.md`:

- Это **горячая ниша импортозамещения**.
- Президентское давление работает (мы видели критику Мирзиёева
  в марте 2026).
- $12,5 млн — реалистичный CAPEX-ориентир для аналогичного завода.
- IRR 21,9% и DPP 5,5 лет — приемлемые для инвестора параметры.

### 5.2. Аналогичный проект для Кашкадарьи — логика

`[ИДЕЯ — конкретные параметры требуют отдельного расчёта]`

| Параметр | Бенчмарк SHANAZ | Что меняется для Кашкадарьи |
| --- | --- | --- |
| CAPEX | $12,5 млн | $10–15 млн (меньше, если сфокусироваться) |
| Площадка | Ташкентская обл. | **СЭЗ «Чирокчи»** (10 лет налоговых льгот) |
| Продуктовый микс | Фарма 48% + косметика 30% + быт. химия 22% | **Фокус на бытовой химии и косметике** (фарма требует GMP-серьёзной — отдельный кейс) |
| Сырьё для упаковки (ПЭТ, ПЭ-канистры) | Импорт или местный ПЭТ | **Прямая поставка с ШГХК** — Кашкадарьинское преимущество |
| ПАВ-сырьё (алкилбензол) | Импорт | Импорт (в РУз пока не делают) — то же |
| Каустическая сода | Импорт + 75 кт от Узкимёсаноата | То же; можно перевозить с Чирчика |
| Логистика на ЦА юг и Афганистан | Из Ташкента — далеко | **Кашкадарья ближе к юж. границам** — преимущество |
| Целевые рынки | РУз + 33% экспорт | РУз + Туркменистан + Афганистан + Иран |

### 5.3. Не дублировать SHANAZ, а дополнять

SHANAZ покрывает Ташкентскую область. **Кашкадарьинский проект
должен быть отстроен по другому профилю**, чтобы не конкурировать
лоб в лоб:

`[ИДЕЯ]`:

- **Не лезть в фарму** — там GMP, лицензии, риски, и Ташкент уже
  закрывает.
- **Сфокусировать на бытовой химии + косметике** в массовом сегменте.
- **Использовать преимущество ШГХК** на упаковке — это
  индивидуальный «ров», которого нет ни у SHANAZ, ни у POKSON,
  ни у UNIGROUP NAVOIY.
- **Целиться на южный коридор** (КД → Сурхандарья → Афганистан;
  КД → Туркменистан) — где Ташкент и Навои логистически дальше.
