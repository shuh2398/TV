## 3. Чек-лист проверки перед запуском

### 3.1 Конкуренты в Узбекистане

- [ ] Проведён анализ существующих производителей в УЗ по данной номенклатуре

> НЕ ЗНАЮ ДОСТОВЕРНО: данные о конкурентах не верифицированы до заполнения выше.

### 3.2 Санкционная проверка

- [ ] Проверен потенциальный партнёр по списку SDN OFAC [дата проверки: ]

- [ ] Проверены цепочки поставок на наличие подсанкционных лиц
- [ ] Юрисконсульт подтвердил допустимость сделки [источник: ]
- [ ] Банк подтвердил возможность проведения платежей [источник: ]

> Подробнее: `risks/sanctions-check.md`

### 3.3 Спрос и рынок сбыта

- [ ] Определён целевой рынок (УЗ / экспорт / оба)

> НЕ ЗНАЮ ДОСТОВЕРНО: спрос без исследования рынка является предположением.
