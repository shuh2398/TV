# Гузарский район — пластиковые изделия на базе ШГХК

> Продукт ODOP с **подтверждённым работающим якорным предприятием** —
> Шуртанский газохимический комплекс (ШГХК), часть АО «Узбекнефтегаз».
> Идея: район производит не само сырьё (его делает ШГХК), а **изделия
> из полиэтилена и полипропилена** — плёнка, упаковка, трубы,
> технические изделия. Классическая китайская модель «龙头企业»
> (dragon head enterprise) — крупный якорь + кластер малых
> переработчиков.

---

## 1. Идентификация

- **Район:** Гузарский район (Ғузор тумани), Кашкадарьинская область
- **Продукт ODOP:** Изделия из полимеров (полиэтиленовая плёнка,
  упаковка, трубы, тара, технические изделия) на базе сырья ШГХК
- **Slug:** `guzar-plastic`
- **Отрасль:** Нижний передел нефтехимии — переработка полимеров
- **Статус:** `[ФАКТ]` — якорь действует и расширяется
- **Тип «двигателя» по китайской типологии:** **dragon head enterprise**
  (вариант 2 из китайских 4-х: кооператив / якорь / ритейл / инвестор)

### 2.3. Связь с GTL-комплексом `[ФАКТ]`

Рядом с ШГХК действует завод **«Uzbekistan GTL»** — крупнейшее
нефтехимическое предприятие региона. Параметры по поисковой выдаче
(uzdaily.uz, upstreamonline.com):

- 307 000 т авиакеросина / год
- 724 000 т дизеля / год
- 437 000 т нафты / год — **передаётся на ШГХК как сырьё**
- 53 000 т СУГ / год
- До 3,6 млрд м³ метана / год на входе

Из 437 кт нафты ШГХК получает 285 кт этилена + 100 кт пропилена
дополнительно (uzliti-en.com). То есть ШГХК + GTL образуют
**связанный нефтехимический хаб** в одном районе — уникальная
ситуация для ODOP.

`confidence: high` — данные подтверждены тремя независимыми
источниками отрасли.

## 3. Почему это лучший «якорь» для ODOP

`[ГИПОТЕЗА, выведена из ФАКТОВ выше]`

Сравнение трёх крупных промышленных якорей области:

| Кандидат | Продукт | Подходит для ODOP? | Почему |
| --- | --- | --- | --- |
| **ШГХК (Гузар)** | Полиэтилен / полипропилен | **Да, очень** | Базовый полимер — сырьё для тысяч малых переработчиков. Можно построить «кластер пластиковой переработки» вокруг |
| Uzbekistan GTL (Гузар) | Авиакеросин, дизель, нафта | Нет | Топливо — единый продукт без «нижнего передела» в районе |
| Дехканабадский калийный завод | Хлористый калий | Слабо | Монопродукт; экспорт в трейдеры — нет «кластера вокруг» |

**Ключевое отличие ШГХК:** полимер — это не конечный продукт, а
сырьё. Это значит, что вокруг ШГХК можно посадить **20–50 малых и
средних предприятий** (МСП) по производству:

- полиэтиленовой плёнки (упаковочной, парниковой, технической);
- ПЭТ-преформ и тары;
- полипропиленовых мешков (для удобрений, муки, цемента);
- полимерных труб (водоснабжение, газоснабжение, канализация);
- технических изделий (фитинги, профили, контейнеры);
- БОПП-плёнок и многослойных упаковочных материалов.

Это **классическая китайская модель** «龙头企业 + 中小企业»
(якорь + МСП), которая применялась в провинциях Чжэцзян, Гуандун
для развития нефтехимических кластеров.

## 4. Дорожная карта продукта (применение Фаз 0–5 ODOP)

### Фаза 0–1: что уже есть `[ФАКТ]`

- Якорь работает (ШГХК, действует с 2001 г. `[НЕ ЗНАЮ ДОСТОВЕРНО]`).
- Сырьё в избытке (140+285 кт этилена, расширение до 430 кт).
- Государство уже инвестирует $1,8 млрд в расширение.
- Логистика — железная дорога Карши–Гузар–Термез.

### Фаза 2: что нужно для запуска кластера

| Задача | Кто отвечает | Срок |
| --- | --- | --- |
| Аудит существующих переработчиков ПЭ в Гузарском районе | Хокимият + ТПП | 1–2 мес. |
| Договор с ШГХК о приоритетном выделении сырья кластеру | Узбекнефтегаз | 3 мес. |
| Льготный режим для МСП-резидентов (земля, налоги, кредиты) | Хокимият + Минэкономики | 3 мес. |
| Привлечение 5–10 «сидов» — малых производителей готовых изделий | Агентство по продвижению инвестиций | 6 мес. |
| Линия логистики готовой продукции на экспорт (ж/д контейнеры) | Узжелдор + хокимият | 6 мес. |

### Фаза 3–4: продуктовая программа

**4 инструмента** (по китайской модели) применительно к Гузарскому
полимерному кластеру:

#### A. Authority — НПА `[ФАКТ существование, детали — НЕ ЗНАЮ]`

- Постановление Президента РУз № ПП-2807 от 09.02.2017 «О мерах по
  ускоренному развитию химической промышленности» `[НЕ ЗНАЮ ДОСТОВЕРНО актуальный статус]`
- Программа развития нефтехимии РУз `[НЕ ЗНАЮ ДОСТОВЕРНО реквизиты]`
- Возможный новый НПА по локализации переработки полимеров

→ Вопрос GUZAR-1 в `questions-open.md`.

#### B. Resources — финансирование

- Льготные кредиты Фонда реконструкции и развития РУз `[НЕ ЗНАЮ ДОСТОВЕРНО доступность]`.
- Инвестиции через UzIPA (Агентство по продвижению инвестиций).
- Возможные международные кредиты (IFC, ADB — нефтехимические МСП).

#### C. Organization — структура кластера

```
ШГХК (полиэтилен, полипропилен — сырьё)
    ↓ контракты на отгрузку гранул
Кооператив переработчиков «Гузар-Полимер» (юр. лицо координатор)
    ↓ распределение сырья, единые стандарты
20–50 малых и средних предприятий-резидентов:
    ├── Производство плёнки (5–10 МСП)
    ├── Производство тары и упаковки (5–10 МСП)
    ├── Производство труб (3–5 МСП)
    ├── Технические изделия (5–10 МСП)
    └── Брендинг и логистика (1–2 трейдера)
```

#### D. Information — стандарты и обучение

- Стандартизация качества продукции МСП (ГОСТ/ТУ/UzST).
- Обучение операторов литья / экструзии (требуется техникум /
  колледж в Карши или Гузаре).
- Маркетинговое исследование внешних рынков (РФ, Казахстан, ЦА).

### Фаза 5: связь с Кировской областью

`[ИДЕЯ — без подтверждения интереса]`

Кировская область РФ — крупный потребитель полимерной продукции
(агроупаковка, трубы для коммунальной инфраструктуры).
Потенциальные направления:

- Полипропиленовые мешки для удобрений → Кировские агрохолдинги.
- Полимерные трубы → коммунальная инфраструктура области.
- Плёнка для теплиц → парниковые хозяйства Кировской обл.

`[ВАЖНО]` — конкретные компании-партнёры из РФ только после
санкционного скрининга по `../risks/sanctions-check.md`. Кроме того,
для пластиковой продукции **санкционные риски минимальны** (это
не dual-use, не электроника, не финансы), но банковская сторона
расчётов всё равно требует проверки.

## 8. Вывод

`[ГИПОТЕЗА на основе совокупности ФАКТОВ]`

**Гузарский район — самый сильный кандидат на пилотный промышленный
ODOP в Кашкадарьинской области.**

Причины:
1. Якорное предприятие **уже существует и расширяется** — это редкая
   ситуация, когда не нужно «создавать двигатель», он работает.
2. Сырьё **избыточное** — 140 кт текущих + 290 кт планируемых
   мощностей этилена.
3. Государство уже **вложило $1,8 млрд** в расширение — намерение
   стратегическое.
4. Полимеры дают **«длинный шлейф» МСП** (плёнка, трубы, тара,
   изделия), а не один монопродукт.
5. Низкий санкционный риск при работе с РФ.

**Yakkabog × виноград** — хороший аграрный кандидат, но «двигателя»
нужно искать.
**Гузар × полимеры** — «двигатель» уже работает, нужно построить
вокруг него кластер МСП.

Для ODOP-программы рекомендуется **запускать в первом пилоте Гузар**,
а Яккабаг ставить во второй пилот.
