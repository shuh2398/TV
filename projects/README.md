# Реестр инвестиционных проектов / Investitsiya loyihalari reyestri

## 🇷🇺 Назначение

В этой папке ведётся реестр приоритетных инвестиционных проектов
Кашкадарьинской области. Каждому проекту рекомендуется создавать
отдельный файл `<год>-<краткое-название>.md` по шаблону ниже.

## 🇺🇿 Maqsad

Ushbu papkada Qashqadaryo viloyatining ustuvor investitsiya loyihalari
reyestri yuritiladi. Har bir loyiha uchun quyidagi shablon asosida
`<yil>-<qisqa-nom>.md` faylini yaratish tavsiya etiladi.
