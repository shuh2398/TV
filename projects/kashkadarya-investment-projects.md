## 4. **Новый сильный вектор: 147 нерудных месторождений**

`[ФАКТ]` Источник: [kapital.uz, поисковая выдача](https://kapital.uz/kashkadarinskaya-oblast/) — «Предприниматели предложили организовать производство готовых товаров на базе **147 нерудных месторождений** Кашкадарьинской области».

`[ИДЕЯ — но с очень крепкой опорой на ФАКТ выше]`

Это огромная неосвоенная база сырья. Нерудные месторождения =
не металлические, обычно это:

- **известняк** → цемент, известь, карбонат кальция (наполнитель пластиков, бумаги, моющих средств)
- **гипс** → строительные смеси, гипсокартон, медицинский гипс
- **мрамор / гранит** → плиты, плитка, экспортные блоки
- **глина** → керамическая плитка, кирпич, санитарная керамика, бентониты для буровых растворов
- **песок / кварц** → стекло, силикон, литейная промышленность
- **базальт** → каменная вата (изоляция для строительства)
- **доломит** → металлургия, стекло, удобрения
- **сера / соли / бариты** → химия

`[НЕ ЗНАЮ ДОСТОВЕРНО]` Точный перечень типов месторождений среди 147 —
требуется выписка из Госкомитета по геологии РУз. Это вопрос INV-3
(см. ниже).

### Почему это важно для продукта «vs Китай»

Все товары из нерудных месторождений объединяет **гигантский
логистический налог**: тяжёлые, объёмные, дешёвые на вес. Ровно та
формула, по которой китайцы проигрывают на рынке ЦА и юга РФ.
И сырьё **локально**, а значит входная цена низкая.

**Сильнейшие категории внутри** (`[ГИПОТЕЗА]` до подтверждения
конкретных месторождений):

| Продукт | Сырьё | Якорь | Спрос |
| --- | --- | --- | --- |
| **Каменная (минеральная) вата** | Базальт | НЕ НАЙДЕН | «1 млн квартир» — теплоизоляция стандарт |
| **Гипсокартон** | Гипс | НЕ ЗНАЮ — но в РУз уже 60 млн м² | Ниша **закрыта** на национальном уровне; в области — НЕ ЗНАЮ |
| **Сухие строительные смеси** | Гипс + цемент + известь | НЕ НАЙДЕН | Активная стройка 2030 |
| **Керамическая плитка** | Глина | НЕ НАЙДЕН | Строительство, замена импортной |
| **Санитарная керамика** | Глина | НЕ НАЙДЕН | Унитазы, раковины — импорт большой |
| **Карбонат кальция** (мел молотый) | Известняк | НЕ НАЙДЕН | Наполнитель: ПЭТ, ПВХ, моющие, краски |
| **Натуральный камень — слэбы для экспорта** | Мрамор/гранит | НЕ НАЙДЕН | Премиум-экспорт |
| **Стекло, стеклотара** | Кварц + сода + известняк | НЕ НАЙДЕН | Импортозамещение |
| **Бентонитовые глины для буровых** | Бентонит | НЕ НАЙДЕН | Газо-нефтяной кластер РУз сам потребляет |

→ Каждая позиция — отдельный потенциальный пилот ODOP по району,
если в этом районе есть соответствующее месторождение.

## 7. Что это меняет в стратегии ODOP

### До этого исследования рекомендация была:

1. Гузар × полимеры (карточка `guzar-plastic.md`)
2. Гузар × ПЭ-трубы (карточка `guzar-pe-pipes-vs-china.md` — поправлена, рынок насыщен)
3. Бытовая химия в Чирокчи СЭЗ (карточка `household-chemicals-market.md`)

### Теперь добавляется:

4. **Минеральные продукты на базе 147 нерудных месторождений** —
   потенциально 13 продуктов по 13 районам, по одному виду сырья
   в каждом. Это **прямое попадание в концепцию ODOP**:

   ```
   Один район = одно нерудное месторождение = один минеральный продукт
   ```

   Например (`[ГИПОТЕЗА]` до получения реестра INV-3):
   - Чирокчи — каменная вата (если базальт)
   - Шахрисабз — мрамор/слэбы
   - Касан — гипсовая продукция
   - Дехканабад — карбонат кальция (на основе известняков около калийного завода)
   - Камаши — керамика на местной глине
   - и т.д.

   Любая из этих позиций тяжёлая для перевозки, выигрывает у Китая по
   логистике, использует локальное сырьё.
