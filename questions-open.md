# Открытые вопросы

Единый список вопросов, по которым на момент внесения записи
**нет задокументированного ответа**. Любое «НЕ ЗНАЮ
ДОСТОВЕРНО» в других файлах репозитория обязано иметь здесь
соответствующий пункт.

## Формат записи

```
### Q-NNN. <Краткая формулировка вопроса>

- Направление: Кашкадарья | Кировская область | двусторонний | процедурный
- Поставлен: YYYY-MM-DD
- Кто может ответить: <орган / ведомство / компания / ФИО>
- Нужен для: <файл или раздел репозитория, где этот вопрос
  блокирует заполнение>
- Предпринятые шаги: <перечень попыток найти ответ>
- Статус: open | in-progress | answered | obsolete
- Ответ (после получения): <текст + ссылка на источник в
  data/sources.md>
- Дата закрытия: YYYY-MM-DD
```

Нумерация сквозная. При закрытии вопроса запись НЕ удаляется —
меняется только статус и добавляется ответ со ссылкой на
первичный источник.
