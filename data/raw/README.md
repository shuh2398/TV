# Сырые материалы

Сюда складываются **первоисточники**: PDF-сканы НПА, выписки из
официальной статистики, скриншоты страниц с датой обращения,
выгрузки реестров.

## Подкаталоги

- `decrees/` — постановления, указы, решения (lex.uz, pravo.gov.ru
  и т. п.). Имя файла: `YYYY-MM-DD_<орган>_<номер>_<краткое название>.pdf`.
- `statistics/` — статистические сборники, выписки Росстата и
  Агентства статистики РУз. Имя файла:
  `YYYY_<источник>_<тема>.<ext>`.
- `screenshots/` — скриншоты веб-страниц с датой обращения. Имя
  файла: `YYYY-MM-DD_<домен>_<тема>.png`.

## Правила

1. Любой файл в `data/raw/` должен быть упомянут в
   [`../sources.md`](../sources.md) с присвоенным ID.
2. Из `data/verified/*.yaml` ссылаться на ID источника, а не на
   путь к файлу напрямую.
3. Не складывать сюда обработанные/синтезированные данные — только
   первоисточники как есть.
4. Не коммитить материалы под закрытой лицензией без проверки прав
   на распространение.
