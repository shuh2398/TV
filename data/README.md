# Открытые данные / Ochiq ma'lumotlar

## 🇷🇺 Назначение

Папка предназначена для публикации машиночитаемых открытых данных
Кашкадарьинской области по инвестиционной тематике:

- свободные земельные участки и производственные площадки;
- объекты государственной собственности, предлагаемые к приватизации;
- статистика внешнеторгового оборота;
- реестр резидентов СЭЗ «Каршы».

Рекомендуемые форматы: **CSV** (UTF-8, разделитель — запятая) и **JSON**.

## 🇺🇿 Maqsad

Papka Qashqadaryo viloyatining investitsiya yo'nalishidagi mashina
o'qiy oladigan ochiq ma'lumotlarini e'lon qilish uchun mo'ljallangan:

- bo'sh yer uchastkalari va ishlab chiqarish maydonchalari;
- xususiylashtirishga taklif etilayotgan davlat mulki ob'ektlari;
- tashqi savdo aylanmasi statistikasi;
- «Qarshi» EIZ rezidentlari reyestri.

Tavsiya etilgan formatlar: **CSV** (UTF-8, vergul ajratuvchi) va **JSON**.

## Правила публикации / E'lon qilish qoidalari

1. Имя файла — латиницей, с датой выгрузки: `zemelnye-uchastki-2026-04.csv`.
2. Первый столбец CSV — уникальный идентификатор записи.
3. Для каждого набора данных добавляется `.md` файл-описание
   (словарь полей, источник, дата актуализации).
4. Персональные данные в открытые наборы **не включаются**.
