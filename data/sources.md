# Реестр источников

В этом файле фиксируются все используемые источники. Каждый источник
должен быть процитирован из `data/verified/*.yaml` и документов в
`projects/` через согласованный идентификатор (например, `UZ-STAT-001`).

Формат записи:

```
### <ID источника>

- **Тип:** официальный документ / статистический сборник / СМИ / отчёт / сайт
- **Название (в оригинале):** …
- **Орган/организация:** …
- **Дата публикации:** YYYY-MM-DD (или период)
- **URL:** …
- **Дата обращения:** YYYY-MM-DD
- **Язык:** ru / uz / en
- **Где используется:** путь к файлу и поле
- **Комментарий:** …
```

Приоритет источников — см. `.cursorrules`, раздел 2.

## Узбекистан — официальные

### UZ-LEX (портал законодательства)

- **Тип:** официальный портал НПА
- **Название (в оригинале):** «Milliy qonunchilik ma'lumotlari ombori» / «Национальная база данных законодательства Республики Узбекистан»
- **URL:** https://lex.uz/
- **Комментарий:** Используется как первоисточник для всех указов
  Президента РУз, постановлений Кабинета Министров и других НПА.
  При цитировании в YAML/Markdown — указывать номер документа,
  дату принятия и дату обращения. Сам факт того, что lex.uz —
  официальный портал, нужно подтвердить ссылкой на НПА о его статусе
  (НЕ ЗНАЮ ДОСТОВЕРНО конкретный документ).

### UZ-STAT (Агентство статистики РУз)

- **Тип:** официальная статистика
- **Название (в оригинале):** «O'zbekiston Respublikasi Prezidenti huzuridagi Statistika agentligi» / «Агентство статистики при Президенте Республики Узбекистан»
- **URL:** https://stat.uz/
- **Комментарий:** Источник по ВРП, демографии, промышленности,
  внешней торговле и пр. При цитировании — указывать конкретный
  сборник/публикацию, страницу, дату обращения.

### UZ-KASHKADARYA-HOK (хокимият Кашкадарьинской области)

- **Тип:** официальный сайт органа исполнительной власти
- **Название (в оригинале):** «Qashqadaryo viloyati hokimligi» / «Хокимият Кашкадарьинской области»
- **URL:** _подтвердить (предположительно qashqadaryo.uz / kashkadarya.uz — НЕ ЗНАЮ ДОСТОВЕРНО, требуется проверка)_

## Россия — официальные

### RU-ROSSTAT (Росстат)

- **Тип:** официальная статистика
- **Название (в оригинале):** Федеральная служба государственной статистики (Росстат)
- **URL:** https://rosstat.gov.ru/
- **Комментарий:** Базовый источник по социально-экономическим
  показателям субъектов РФ. Канонический сборник — «Регионы России.
  Социально-экономические показатели». Год выпуска и дата обращения
  фиксируются при цитировании.

### RU-PRAVO (официальный портал правовой информации)

- **Тип:** официальный портал НПА
- **Название (в оригинале):** Официальный интернет-портал правовой информации
- **URL:** http://publication.pravo.gov.ru/
- **Комментарий:** Источник для федеральных и региональных НПА РФ.

### RU-FCS (ФТС России)

- **Тип:** таможенная статистика
- **Название (в оригинале):** Федеральная таможенная служба
- **URL:** https://customs.gov.ru/
- **Комментарий:** Используется для верификации внешнеторговых
  показателей региона.

### RU-KIROV-GOV (Правительство Кировской области)

- **Тип:** официальный сайт органа исполнительной власти
- **Название (в оригинале):** Правительство Кировской области
- **URL:** https://www.kirovreg.ru/
- **Комментарий:** Канонический портал. Структура министерств,
  актуальный губернатор и контакты — фиксировать при первом цитировании
  с указанием даты обращения.

### RU-KIROV-INVEST (инвестиционный портал/корпорация развития)

- **Тип:** официальный сайт
- **URL:** _НЕ ЗНАЮ ДОСТОВЕРНО актуальное название и URL — требуется проверка по ссылкам с RU-KIROV-GOV_

## Нерекомендуемые и запрещённые «источники»

- Анонимные Telegram-каналы без указания первоисточника.
- Форумы, отзывы, рекламные баннеры.
- Собственные «оценки» без методики и данных.

Если такой материал попал в работу — он идёт не сюда, а в
`questions-open.md` как требующий проверки.
