# Реестр источников

Единый журнал источников, на которые ссылаются файлы в `data/verified/`,
карточки стейкхолдеров, проекты и аналитические записки.

Правила:

1. Каждая запись получает идентификатор вида `S-YYYY-NNN`
   (год + порядковый номер в году).
2. Идентификатор используется в YAML-полях `source: S-2026-001` или
   как ссылка `[S-2026-001](./sources.md#s-2026-001)`.
3. Для каждого источника указываются:
   - **Оригинальное название** документа/страницы (без перевода).
   - Автор/издатель.
   - Дата публикации (`YYYY-MM-DD`, если известна).
   - URL или путь в репозитории.
   - Дата обращения (для веб-источников).
   - Тип: официальный документ / сайт госоргана / СМИ / статистика /
     пресс-релиз компании / интервью / прочее.
   - Язык оригинала.
4. Если документ сохранён локально — кладётся в `data/verified/_raw/`
   и ссылка на локальную копию указывается дополнительно.
5. Удалять записи нельзя — помечать `status: withdrawn` с причиной.

---

## Шаблон записи

```markdown
### S-YYYY-NNN

- **Название (оригинал):**
- **Автор / издатель:**
- **Дата публикации:**
- **URL:**
- **Локальная копия:**
- **Дата обращения:**
- **Тип:**
- **Язык:**
- **Используется в:** (перечень файлов)
- **Примечание:**
```

## Источники

_Записей пока нет. Пока реестр пуст, все поля в `data/verified/*.yaml`
должны оставаться `null` с пометкой «НЕ ЗНАЮ ДОСТОВЕРНО»._
