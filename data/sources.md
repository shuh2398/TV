# Реестр источников

В этом файле фиксируются все используемые источники. Каждый источник
должен быть процитирован из `data/verified/*.yaml` и документов в
`projects/` через согласованный идентификатор (например, `UZ-STAT-001`).

Формат записи:

```
### <ID источника>

- **Тип:** официальный документ / статистический сборник / СМИ / отчёт / сайт
- **Название (в оригинале):** …
- **Орган/организация:** …
- **Дата публикации:** YYYY-MM-DD (или период)
- **URL:** …
- **Дата обращения:** YYYY-MM-DD
- **Язык:** ru / uz / en
- **Где используется:** путь к файлу и поле
- **Комментарий:** …
```

Приоритет источников — см. `.cursorrules`, раздел 2.

## Нерекомендуемые и запрещённые «источники»

- Анонимные Telegram-каналы без указания первоисточника.
- Форумы, отзывы, рекламные баннеры.
- Собственные «оценки» без методики и данных.

Если такой материал попал в работу — он идёт не сюда, а в
`questions-open.md` как требующий проверки.
