# Инвестиционный портал Кашкадарьинской области

# Qashqadaryo viloyati investitsiya portali

---

## 🇷🇺 Русский

Официальный репозиторий материалов по инвестиционной деятельности
Кашкадарьинской области Республики Узбекистан.

Репозиторий ведётся аппаратом заместителя хакима Кашкадарьинской области
по вопросам инвестиций, внешнеэкономических связей, инновационного
развития, информационных технологий и коммуникаций.

### Цели проекта

- Сбор и публикация информации об инвестиционных возможностях региона.
- Ведение реестра приоритетных инвестиционных проектов.
- Прозрачное представление льгот, преференций и условий работы в
  свободной экономической зоне «Каршы».
- Предоставление инвесторам единой точки входа для ознакомления с
  регионом.

### Направления работы

1. **Инвестиционный потенциал Кашкадарьинской области** —
   системное описание региона, отраслей, СЭЗ «Qarshi»,
   действующих льгот и проектов.
2. **Поиск партнёров в Кировской области Российской Федерации** —
   идентификация органов власти региона, институтов развития и
   компаний, потенциально заинтересованных в кооперации с
   Кашкадарьинской областью; обязательная комплаенс- и
   санкционная проверка каждого российского контрагента.

### Дисциплина данных

Работа в репозитории ведётся по принципу **«ноль галлюцинаций»**.
Правила зафиксированы в [`.cursorrules`](.cursorrules):

- ни одна цифра не публикуется без указания источника;
- ни одно утверждение о заинтересованности организации не
  публикуется без задокументированного подтверждения;
- при отсутствии данных — пометка `НЕ ЗНАЮ ДОСТОВЕРНО` и запись
  в [`questions-open.md`](questions-open.md);
- официальные названия документов, органов и программ — в оригинале.

## 🇺🇿 O'zbekcha

O'zbekiston Respublikasi Qashqadaryo viloyatining investitsiya faoliyatiga
oid materiallarning rasmiy ombori.

Ombor Qashqadaryo viloyati hokimining investitsiyalar, tashqi iqtisodiy
aloqalar, innovatsion rivojlanish, axborot texnologiyalari va
kommunikatsiyalar masalalari bo'yicha o'rinbosari apparati tomonidan
yuritiladi.

### Loyiha maqsadlari

- Viloyatning investitsiyaviy imkoniyatlari haqidagi ma'lumotlarni
  to'plash va e'lon qilish.
- Ustuvor investitsiya loyihalari reyestrini yuritish.
- «Qarshi» erkin iqtisodiy zonasida imtiyoz va preferensiyalarni
  shaffof tarzda taqdim etish.
- Investorlar uchun yagona ma'lumot nuqtasini ta'minlash.
