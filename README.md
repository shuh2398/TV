# Кашкадарья ↔ Кировская область: инвестиции и партнёрство

Рабочий репозиторий по двум связанным направлениям:

1. **Инвестиционный потенциал Кашкадарьинской области**
   (Qashqadaryo viloyati, Республика Узбекистан).
2. **Поиск партнёров в Кировской области**
   (Российская Федерация).

Репозиторий используется для сбора и проверки информации,
подготовки материалов для переговоров и ведения реестра открытых
вопросов. Рабочий язык — русский. Официальные названия документов,
законов, организаций и административных единиц приводятся в
оригинале.

---

## Главный принцип

**Ни одной цифры и ни одного утверждения о заинтересованности
компаний без задокументированного источника.**

Подробные правила — в файле [`.cursorrules`](.cursorrules). Они
распространяются и на AI-ассистентов, и на людей, редактирующих
репозиторий.

Если данных нет — в документе пишется «**НЕ ЗНАЮ ДОСТОВЕРНО**»,
а вопрос переносится в [`questions-open.md`](questions-open.md).

## Как вносить данные

1. Любое число, имя, название, сумма, срок или льгота — только
   со ссылкой на первичный источник (закон, постановление,
   официальный сайт ведомства, статистический сборник).
2. Источник фиксируется одновременно в двух местах:
   - в поле `source` соответствующей записи YAML
     (`data/verified/*.yaml`);
   - в реестре [`data/sources.md`](data/sources.md).
3. Если источник вторичный (СМИ, презентация, пересказ) —
   ставится пометка «требует подтверждения», и вопрос
   дублируется в [`questions-open.md`](questions-open.md).
4. Перед добавлением любой российской компании в
   `stakeholders/ru/` выполняется проверка по процедуре
   [`risks/sanctions-check.md`](risks/sanctions-check.md).
